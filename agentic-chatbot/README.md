# Orbit — Agentic-Style Chatbot

A responsive, dark-themed chatbot UI built with React + Vite. Includes an action-plan preview, chat starters, task checklist, session activity, copy responses, and English/Hindi toggle.

## Run locally
1. Install Node.js (18+ recommended).
2. Extract this ZIP and open the `agentic-chatbot` folder in a terminal.
3. Run:
   ```bash
   npm install
   npm run dev
   ```
4. Open the local URL printed by Vite (usually `http://localhost:5173`).

## Build
```bash
npm run build
npm run preview
```

## Important
This is a front-end demo. It uses simple local response logic and does **not** connect to an actual AI model or external agent tools. To make it a real AI chatbot, connect a backend API and keep the model API key on the server, never in frontend code.
